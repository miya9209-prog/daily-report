MISHARP DAILY REPORT v3.4.8 — Google 백필 환경변수/워크플로우 오류 수정 통합본

원인:
- v3.4.7의 scripts/backfill_cafe24.py는 Google 광고비 백필을 호출했지만,
  실제 GitHub에서 실행된 backfill workflow는 이전 버전이라 Google 관련 Secret을 env로 넘기지 않았음.
- 로그에서 Step 이름이 'Backfill Cafe24'였고 GOOGLE_SERVICE_ACCOUNT_JSON 등이 env 목록에 없었음.
- 그래서 Cafe24는 기간 끝까지 정상 저장된 뒤 마지막 Google 단계에서 실패함.

이번 수정:
1. Cafe24 백필과 Google 광고비 백필을 GitHub Actions에서 별도 Step으로 분리
   - Cafe24가 끝난 뒤 Google이 실패해도 원인 구분이 명확함
2. Google 전용 스크립트 scripts/backfill_google_ads.py 추가
   - 실행 시작 즉시 필수 환경변수 사전검사
   - Secret 누락이면 20분 기다린 뒤가 아니라 즉시 명확한 오류 표시
3. Google 광고비 전용 수동 workflow 추가
   - MISHARP Google ad cost backfill
   - 이미 Cafe24가 완료된 기간은 Cafe24를 다시 돌리지 않고 광고비만 복구 가능
4. 기존 MISHARP backfill도 앞으로는 Cafe24 + Google 광고비를 순차 수행
5. 6개월 백필/일일보고 보호/웹북마크/회원가입/iApps/Sellmate 등 v3.4.7 이전 누적 수정 모두 포함

반드시 덮어쓸 핵심 파일:
- .github/workflows/backfill.yml
- .github/workflows/backfill_google_ads.yml  (신규)
- scripts/backfill_cafe24.py
- scripts/backfill_google_ads.py           (신규)

중요:
- GitHub Actions Secrets에는 기존대로 다음 이름이 있어야 함:
  GOOGLE_SERVICE_ACCOUNT_JSON
  AD_SHEET_ID
  AD_SHEET_GID
  AD_SHEET_DATE_HEADER
  AD_SHEET_COST_HEADER
- 새 Secret을 만드는 것이 아니라 기존 Secret을 최신 workflow가 전달하도록 고친 것.

현재 실패한 2026-06-01~2026-08-26 작업은 Cafe24 부분이 이미 끝까지 정상 저장되었으므로
패치 적용 후 'MISHARP Google ad cost backfill'만 같은 기간으로 실행하면 됨.
