MISHARP DAILY REPORT v3.3.9 — 일별통계/웹북마크/회원가입/오늘기본 통합 패치

이번 ZIP 하나만 덮어쓰면 v3.3.8의 최근 수정 + 아래 신규 수정이 함께 반영됩니다.

신규 수정
1. 일별 통계: 최근 날짜가 가장 위에 표시
2. 웹북마크: 전체방문 - 광고유입 - 검색방문으로 자동 계산
   - 기존 DB의 웹북마크가 비어 있어도 화면/비교에서 즉시 계산
   - 새 Cafe24 수집/백필 시 DB bookmark_visits에도 저장
3. 회원가입
   - Cafe24 Admin /dashboard의 new_members_count 사용
   - mall.read_store scope를 OAuth 승인 링크에 자동 포함
   - 기존 토큰 사용자는 데이터·설정에서 Cafe24 인증 링크를 1회 다시 승인해야 함
   - dashboard는 오늘 신규회원 값이므로 오늘 수집시에만 저장
4. 기본 조회기간: 이번 달이 아니라 오늘
5. 핵심지표 제목
   - 오늘: '오늘의 핵심 지표'
   - 단일 과거일: 'YYYY-MM-DD 핵심 지표'
   - 여러 날짜: '선택기간 핵심 지표'
