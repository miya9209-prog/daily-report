MISHARP DAILY REPORT v3.4.3 — 과거자료 파생지표 마무리 통합본

이 ZIP은 v3.4.2까지의 모든 수정사항을 포함한 누적본입니다.
이 ZIP 하나만 경로 그대로 덮어쓰면 됩니다.

[이번 수정]
1. 과거 일일보고의 광고비율 자동 계산
   - 광고비율(%) = 일별 광고비 / 실결제 × 100
   - DB 값이 비어 있어도 화면, 동일기간 비교, XLSX에서 즉시 계산

2. 웹북마크 자동 계산 유지/강화
   - 웹북마크 = 전체방문 - 광고유입 - 검색방문
   - 세 원천값이 모두 있는 날짜만 자동 계산
   - 검색방문 원천 자체가 없는 과거 날짜는 '자료없음' 유지

3. 상품 퍼널 비율 자동 계산
   - 상품조회/장바구니/상품주문 원천 수치가 있는데 비율만 없으면 자동 계산

4. 과거 Excel importer도 앞으로 같은 파생지표를 계산해 저장
   - 광고비율
   - 웹북마크

[중요]
- 기존 과거 일일보고 Excel은 다시 업로드할 필요 없습니다.
- 이미 PostgreSQL DB에 적재된 원천값으로 조회 시 자동 계산합니다.
- 원본에도 없는 검색방문, 상품조회, 장바구니, 상품주문은 임의 추정하지 않고 '자료없음' 유지합니다.

DB schema / Secrets 변경 없음.
