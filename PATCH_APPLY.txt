MISHARP DAILY REPORT v3.4.0 — 일별 종합통계 UI/조회 로직 개편 통합본

이 ZIP은 바로 전 v3.3.9의 모든 수정사항을 포함합니다.
따라서 v3.3.9를 별도로 적용할 필요 없이 이 ZIP 하나만 덮어쓰면 됩니다.

[이번 UI 개편]
1. 일별 종합통계 타이틀 다음에 '오늘의 핵심 지표'
   - 조회기간과 무관
   - 항상 오늘 당일 데이터만 조회
   - 아래 기간 버튼을 눌러도 절대 월누계/기간누계로 바뀌지 않음

2. 조회기간 위치 이동
   - 오늘의 핵심 지표 아래
   - 조회기간별 통계 바로 위
   - 오늘 / 어제 / 최근 7일 / 이번 달 / 지난달 / 직접 선택

3. '일별 통계' 제목 → '조회기간별 통계'
   - 선택한 조회기간만 표시
   - 최근 날짜가 가장 위

4. '시간대별 매출·주문·방문 보기' 완전 삭제
   - 화면 삭제
   - 일별 XLSX의 시간대 시트도 삭제

5. '전년도 · 전전년도 동일기간 비교'
   - 조회기간별 통계 바로 아래 배치
   - 위에서 선택한 조회기간에 따라 자동 변경
   - 예: 2026-08-01~08-26 선택 시
     2025-08-01~08-26 / 2024-08-01~08-26 비교
