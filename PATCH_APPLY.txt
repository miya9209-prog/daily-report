운영 방식 변경:
- Cafe24 재고는 실제 재고가 아니므로 절대 사용하지 않음
- Sellmate 실제 재고: 데이터·설정에서 Excel 수동업로드
- iApps 앱 통계: 데이터·설정에서 Excel 수동업로드
- 같은 Sellmate 기준일 재업로드 시 해당 날짜 재고 스냅샷을 통째로 교체
- iApps는 날짜별 앱 설치수/앱 순방문을 upsert하여 덮어쓰기
- Google 광고비는 기존 GitHub Actions 자동수집 유지

파일 형식:
- xlsx / xls / csv 지원
- 헤더는 자동 탐지
- 파일 구조를 인식하지 못하면 실제 컬럼명이 필요하다는 오류를 보여줌

중요:
실제 Sellmate/iApps 샘플 파일을 한 번 업로드해보고 헤더 자동탐지가 실패하면,
그 파일의 실제 헤더에 맞춰 alias를 한 번만 보완하면 이후에는 같은 형식으로 계속 사용 가능합니다.
