# 06. 기존 미샵 월별 일일보고 과거 데이터 세팅

## 대상
`★★미샵일일보고-2022년.xlsx`

파일명은 2022년이지만 기존 확인 결과 월별 시트에 여러 연도의 일별 통계가 누적되어 있으므로, `연도년월` 형식의 시트명을 자동 탐지합니다.

## 지원 항목
- 실결제
- 광고비
- 구매건수(있는 구간)
- 객단가
- 전환율
- 전체방문
- 페이지뷰
- 검색방문
- 광고유입
- 웹북마크
- 앱 설치수
- 앱 순방문
- 택배수량
- 회원가입

## 1. dry run

```bash
python -m scripts.import_legacy_daily_report "★★미샵일일보고-2022년.xlsx" --dry-run
```

## 2. 실제 적재

```bash
python -m scripts.import_legacy_daily_report "★★미샵일일보고-2022년.xlsx"
```

## 3. 처리 원칙
- 날짜 형식 혼재 자동 보정
- `0.0236` 전환율은 `2.36%`로 정규화
- 헤더 위치가 달라도 항목명을 찾아 mapping
- 없는 값은 0이 아니라 NULL(화면 `자료없음`)
- 기존 API 데이터가 있는 날짜는 존재하는 source 기록과 함께 필요한 값만 갱신

## 4. 비교표
사용자가 2026-08-01~2026-08-19를 선택하면:
- 현재: 2026-08-01~08-19
- 전년도: 2025-08-01~08-19
- 전전년도: 2024-08-01~08-19

비율 지표는 `%p`, 금액/건수는 증감률로 비교합니다.
