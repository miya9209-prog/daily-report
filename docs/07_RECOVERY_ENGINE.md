# 07. 매출복구 판단엔진

이 기능이 v2의 핵심입니다. 숫자를 보는 데서 끝나지 않고 **오늘 무엇을 바꿀지** 판단하게 합니다.

> 현재 `매출광고/재고회수` 분류는 Cafe24 퍼널 + Sellmate 재고 기준의 **운영 후보 판정**입니다. Google Sheet는 일별 총광고비만 제공하므로, 상품별 Meta ROAS가 연결되기 전에는 광고성과 확정판정으로 사용하지 않습니다. 2차 확장은 `10_META_AND_CRM_PHASE2.md`를 참고하세요.

## 1. 매장 전체 경보

### 유입 정상 / 전환 약화
최근 7일 평균 방문 수준은 유지되는데 전환율이 설정비율 이하로 내려가면:

```text
광고 증액보다 상품·상세·오퍼 개선 우선
```

### 조회→장바구니 약화
장바구니율이 최근 평균보다 크게 낮아지면:

```text
상품 소재/핏/가격/혜택 메시지 점검
```

### 광고비율 과다

```text
광고비 / 실결제 × 100 >= HIGH_AD_COST_RATIO
```

이면 승자상품 집중/저효율 중단 경보.

## 2. 상품별 자동판정

### 매출광고
- 주문수 >= `WINNER_MIN_ORDERS`
- 구매전환율 >= `WINNER_MIN_CVR`

### 재고회수
- 재고 >= `RECOVERY_MIN_STOCK`
- 최근 주문 또는 장바구니 증거 존재

### CRM회수
- 조회 충분
- 장바구니 충분
- 장바구니→주문율 낮음

즉, 상품 자체 관심은 있는데 구매직전 이탈이 발생하므로 쿠폰/배송/사이즈 확신/리마인드가 우선.

### 상세개선
- 조회 충분
- 조회→장바구니율 약함

즉, 광고 유입보다 상세 첫화면/숏폼/가격/상품 매력이 먼저.

### 광고중단(재고)
- 팔리지만 판매가능재고가 거의 없음

### 중단/관찰
- 조회 표본은 충분한데 장바구니/주문 증거 없음

## 3. 설정값
`.env`/Secrets에서 조정:

```text
WINNER_MIN_ORDERS=2
WINNER_MIN_CVR=2.0
RECOVERY_MIN_STOCK=10
DETAIL_MIN_VIEWS=50
CART_RESCUE_MIN_CARTS=3
WEAK_CART_RATE=4.0
WEAK_CART_TO_ORDER_RATE=20.0
STORE_ALERT_RATIO=0.80
HIGH_AD_COST_RATIO=15.0
```

처음 2주는 자동판정을 그대로 집행하지 말고 기존 운영판단과 비교하여 미샵에 맞게 threshold를 조정합니다.

## 4. 시즌 재고

```text
필요일판매 = 판매가능재고 / 시즌남은일
소진속도달성률 = 최근 일평균판매 / 필요 일판매 × 100
```

- 100% 이상: 현재 속도면 시즌 내 소진 가능
- 100% 미만: 현재 속도 부족

이 값으로 재고회수 광고/CRM/기획전 우선순위를 결정합니다.
